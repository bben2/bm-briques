# Brick kit réutilisable

Rendu procédural dans `js/game.js` (fonctions `drawBrick`, `drawStud`, `drawMinifig`, `drawWall`, `drawArch`).

Palette pierre de Jérusalem :
- top `#f0dcb8`
- front `#d7bc8e`
- side `#b89568`
- grout `#8a6f4e`
- gold UI depuis `?couleurs=`

Les figurines sont des briques maison (tête + torse + jambes/jupe). Aucune marque déposée.

Exporter une spritesheet : ouvrir le jeu, `window.BM.exportKit()` dessine les modules hors écran (hook prêt).
